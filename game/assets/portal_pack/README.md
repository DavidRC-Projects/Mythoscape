# Castle Realm Portal pack

OSRS low-poly **stone ring** portal for Mythoscape’s Castle Realm entrance/return — matches the **wishing well** and castle flat-shaded stone, with carved runes, gold inlay, and a soft purple magical glow (+ cheap 6-frame pulse).

## Score: **8.5/10** vs OSRS portals / wells

**Hits:** Same kit/camera as props (ortho az0 el32); well-like ring + coping; runes/gold castle accents; purple core reads as magic not water; 1x/2x + origins; before/after vs flat purple circle; optional glow GIF; investigation-first Cursor prompt.

**Weaknesses:** Castle Realm portal not on `main` yet (Phase B placeholder); anim is post-pulse on sprite (not true emissive re-render); no yaw variants; pillars are shorter accents not a full arch; void-rift style vertical portal deliberately avoided.
