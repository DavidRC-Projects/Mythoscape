# Fairy village ground pack: notes

## Tiles (`assets/tiles/`, each at 40/80/160 px)
- `fairy_moss_v1..v5`, `petal_path_v1..v5`: each set tiles seamlessly in any order. All variants share a narrow border band. Pick the variant with `fairy_variant(x, y)`, the 5-way hash in GROUND_DETAIL_CURSOR_PROMPT.md.
- `moonstone_paving_v1..v16`: one seamless 4×4-tile crazy-paving texture cut into 16 tiles. Pick with `paving_variant(x, y) = (y % 4) * 4 + (x % 4) + 1`. The joints run across tile borders, so there is no visible 40 px grid.
- Edges (`assets/tiles/edges/`): `path_grass_edge_<mask>` and `paving_grass_edge_<mask>`, 46 masks each. These are transparent grass overlays, blitted on top of a PATH or STONE tile.
  - Bits: N=1, NE=2, E=4, SE=8, S=16, SW=32, W=64, NW=128. A bit is set when that neighbour is grass-like (GRASS, or a WALL whose ground_under is GRASS).
  - A diagonal bit is kept only when both of its orthogonal neighbours are clear. That leaves 47 masks; mask 0 means no overlay.

## Decals (`assets/decals/<id>/`, 1x/2x/4x + meta.json, non-blocking)
- Ground decals: mushroom_ring (2×2), toadstool_cluster, moonpetal_clump, rosebell_clump, fallen_petals, glow_stones, fairy_lantern, fern_clump, pebbles.
- Contact skirts: queens_tree_hall_skirt, moonstone_fountain_rim, lily_fountain_rim.
- Placements:
  - `json/ground_decals.json` holds 66 deterministic placements, regenerated by `src/ground_layout.py`;
  - `json/contact_decals.json` holds the skirts.
- Draw order: terrain, then edges, then skirts, then decals, then the y-sorted entities.
- Check: `python3 src/decal_check.py` (prints OVERALL PASS).

## Dark blocks / collision
- `json/ground_under.json` maps 224 building and fountain WALL tiles to the ground drawn under them: STONE for the fountains, GRASS for the buildings. Collision is unchanged.
- `json/collision_trimmed/*.json` is a **proposal only**. It lists the blocked tiles where less than 50 % of the tile is covered by the 1x sprite:
  - Tree-Hall: 10 tiles;
  - Inn: 3;
  - Apothecary: 9;
  - Lily Fountain: 2;
  - Moonstone Fountain: 0.
- `src/trim_check.py` confirms that stands, NPCs and the dungeon stay reachable, and that doors stay blocked. It passes.

## Regenerate
1. `python3 src/ground/gtex.py [moss path paving]`
2. `src/ground/render_all.sh [names]` (Blender 4.2, 64 samples, about 65 s per tile)
3. `python3 src/ground/post.py tiles edges seams`
4. `src/ground/render_decals.sh`, then `python3 src/ground/decal_post.py`
5. `python3 src/ground_layout.py`
6. `python3 src/decal_check.py`
7. `python3 src/ground/ground_mock.py`
